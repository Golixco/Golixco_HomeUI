# Company-name font subsets

Small subsets of Noto Sans Devanagari, Noto Sans JP and Noto Sans Arabic from Google Fonts, used only to render the multilingual Golixco placeholder on systems missing those scripts.

Source: https://fonts.googleapis.com/css2 (family-specific `text` subsets, weight 500).
Original font sources and licenses: https://github.com/google/fonts/tree/main/ofl/notosansdevanagari , https://github.com/google/fonts/tree/main/ofl/notosansjp , https://github.com/google/fonts/tree/main/ofl/notosansarabic .

Each accompanying OFL file contains the corresponding copyright notice and SIL Open Font License. Source fonts and licensing are preserved; the generated subsets do not define a new brand logo.

Mission 02 adds local Google Fonts text subsets of Inter (reading typography), Noto Sans SC (Simplified Chinese), Noto Sans KR (Korean), and Noto Sans (Greek/Cyrillic), at weights 400/500/600/700. Each corresponding OFL file retains its copyright and redistribution license.
